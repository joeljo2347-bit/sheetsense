1. Your sheet becomes tables

Titles above the headings, money typed as text and Total rows are cleaned up, so every column has a proper type.

2. A model writes one query

An open model running on this server reads your question and the column names, and writes a single read-only SQL query.

3. The database does the math

SQLite computes every figure, so totals are exact. Mistakes are sent back to the model to fix, and you see the query it used.

Files you upload are read in memory for your question and then discarded. Nothing is sent to an outside AI service. The example company and its data are made up.
